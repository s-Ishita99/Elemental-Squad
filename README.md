# Elemental Squad

Elemental Squad is a graphical puzzle-based game developed as a PBL project.

## Objective

The project aims to create an interactive game that demonstrates the practical
application of Data Structures and Object-Oriented Programming concepts.

## Technologies

- C
- C++
- Raylib

## Main Concepts

- Object-Oriented Programming
- Data Structures
- Character abilities
- Grid-based levels
- Game logic
- File handling
